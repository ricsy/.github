# Contributing

## Language

- Use Simplified Chinese for collaboration notes, issues, and reviews by default.
- Keep code, commands, config keys, and user-facing CLI text in English unless the repository says otherwise.

## Issue Discipline

- Prefer issue templates over blank issues.
- Keep one issue focused on one topic.
- For framework gaps, write the background, problem, reproduction or proposal, and expected result clearly.

## Change Discipline

- Prefer atomic commits.
- Verify the exact scope before commit and push.
- Do not mix unrelated changes in one pull request.
